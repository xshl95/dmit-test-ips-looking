# DMIT 测试 IP：洛杉矶/香港/东京全节点测速地址，附 Looking Glass 查回程与套餐对照

买 VPS 之前先 ping 一下，这动作很多人都会。问题是大多数人只 ping 得到一个数字，然后凭这个数字下单——结果拿到机器才发现高峰期绕路、晚八点丢包。

DMIT 提供了官方 Looking Glass（LG）和一组测试 IP，覆盖洛杉矶、香港、东京三个机房。会用的人能在付款前把去程、回程、带宽兑现率都摸清楚；不会用的人对着一串数字看半天。下面把测试地址、对应线路和实操步骤摊开讲。

先说一个前提：DMIT 的线路是按机房 + 等级卖钱的，Pro、EB、T1 是三条不同的路。测试 IP 的意义就在于——让你在掏钱前知道自己这条运营商走的是哪条路。

## 拿到 IP 之后，三步测完再决定买不买

### 第一步：本机 ping 测试 IP，看延迟和丢包

这一步测的是**去程**——你的网络到机房这一段。


ping 154.17.30.96


看两个数：延迟和丢包率。参考值大致是洛杉矶 150–170ms（电信）、香港 10–30ms。丢包 0% 是理想状态，持续 5% 以上就要警惕。抖动也值得留意，延迟数字来回跳说明这条线在路上被抢得厉害。

### 第二步：进 LG 跑 traceroute 或 mtr，看回程

ping 只能告诉你"通不通"，告诉不了你"怎么通的"。LG 的下拉框里有 ping、traceroute、mtr、nexttrace 几个命令，重点用 mtr 或 nexttrace。

流程是：在目标 IP 栏填你自己的公网 IP（机房当源头反测你），点 Run。等几十秒。

然后看每跳的 AS 号，这几个是重点：

- **AS4809** — 电信 CN2 GIA，延迟最稳的那条
- **AS58807** — 移动 CMI / CMIN2，移动方向友好
- **AS9929** — 联通 CUII，联通方向友好
- **AS4134** — 电信 163 普通出口，最便宜也最堵

有一份 LG 实操记录里，lax-pro 节点往广东电信跑出来的结果是终点 0% 丢包、平均 155.6ms，路径里出现 59.43.\* 段的 CN2 地址，最后一跳落在广东电信骨干。这个数据跟"Pro 是三网 CN2 GIA 回程"的说法是能对上的。

一个小坑：mtr 中间跳点丢包不代表真丢包，很多中间路由器会对 ICMP 限速。**只看终点那一跳的 loss%**，终点掉 30% 才是真问题。

### 第三步：拉一份测速文件，看带宽有没有兑现

LG 页面左侧挂了测速文件，IPv4 和 IPv6 各有 100MB / 1GB / 5GB 三档。

想快速验证连通性点 100MB。想看稳态速度别用 100MB，几秒就下完了看不出东西，直接上 1GB 或 5GB。命令行党可以 `wget` 或者 `curl -O`。

判断标准：能跑到承诺带宽的 70% 以上算合格。只能跑到一两成，大概率是超售或者跨网拥堵。还有一点，你本地如果是百兆宽带，那测出来必然不会超过你自己的上限。

LG 里还挂了 iPerf3 server，本地装了客户端的话可以跑双向带宽测试，比单纯下载文件更接近真实带宽。

## Pro、EB、T1：测试 IP 背后是三条不同的路

测完发现延迟高，不一定是机房的问题，很多时候是你选错了系列。

Pro 是三网 CN2 GIA 回程，硬件和线路都堆到顶，价格也最高。适合跨境业务、面向大陆用户的站点、对延迟敏感的生产环境。

EB（Eyeball）回程走 CMIN2 或 CMI，移动用户体验通常更好，价格比 Pro 低一档。个人站、轻度业务、预算有限但还是要大陆访问体验的场景。

T1 是纯国际线路，明确**不含中国优化**。它的定位是国际互联和落地业务，不是拿来给大陆用户当加速节点用的。如果你的测试结果显示 T1 延迟很高，那不是故障，是设计如此。

## 测试 IP 测不出来的四件事

LG 是好工具，但它有边界，这几件事别指望从里面看到：

**回程。** 商家挂出来的 LG 数据大多是从机房往外测的去程。你访问机器的体验更多由回程决定，这一步得自己在本地跑反向 mtr，或者找第三方反测。

**晚高峰。** 你测的时间大概率不是晚上八到十一点。那个时间段才是线路真实下限的暴露时间，也是超售最容易显形的时候。

**IP 纯净度。** ping 和 mtr 全绿，不等于你拿到的 IP 能干净地访问各种服务。有用户在论坛反馈过 DMIT 的 154.17 网段被部分平台标记为高风险的情况。IP 质量要另外查，跟线路质量是两码事。

**长期稳定性。** LG 给的是某一刻的快照。机器三个月后什么状态，它测不出来。

## 顺便说下换 IP 政策

测完下单，还有一件跟 IP 有关的事值得先看：DMIT 的 IP 不是一次买断的。

按公开的规则整理，Pro 和 Eyeball 网络满足几个条件可以免费换 IP：服务器购买超过 7 天、距离上次换 IP 至少 15 天、当前 IP 的 ICMP 和全部 TCP 端口都不通、服务剩余有效期不少于 7 天。不满足免费条件可以付费换，每次 5 美元，条件宽松一些（购买超 24 小时、距上次换 IP 超 24 小时）。Tier 1 网络只支持付费更换，3 天一次，同样 5 美元。

这些规则在不同时间点调整过，也有消息称全系列已支持后台自助操作、部分线路需人工审核。真要换之前，先在后台或工单里确认一遍当前政策。

## 常见问题

**Q：测试 IP 会变吗？**
会。节点扩缩容或者补货都会带出新地址。这也是为什么不要照搬半年前的整理贴，直接开 LG 看页面上的当前 IP。

**Q：没买机器能用 LG 吗？**
能。LG 是公开的，不需要登录，不需要付款，这是它比"自己 ping 一下"更有价值的地方——它让你测到服务商那一侧。

**Q：香港节点为什么延迟最低？**
物理距离决定的。香港到大陆南方城市的链路本身就短，10–30ms 属于正常范围。洛杉矶隔着太平洋，150ms 上下已经是 CN2 GIA 的正常表现了，再低基本要靠专线。

**Q：Pro 和 EB 差的价值在哪？**
主要在回程质量。Pro 三网回程走 CN2 GIA，晚高峰稳定性通常更好；EB 回程走 CMIN2/CMI，移动用户体感接近 Pro，但价格低一档。电信和联通的用户，如果预算允许，Pro 更省心。

## 一句话决策

测试 IP 和 LG 加起来花你十分钟，能挡掉一次买错线路的返工。香港看延迟，洛杉矶看回程，T1 别拿来给大陆用户加速。测完再下单，比测完再退机器便宜得多。
